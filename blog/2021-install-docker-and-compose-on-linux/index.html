2021-10 Linux 轻松安装 Docker v1.29.2 + Docker Compose

2021 年

原载于 2021 年的旧博客（已关闭）

简介

分享自己这一套用于新 Linux 机器快速安装 Docker （CE 社区版本）的方法

安装 Docker

安装 yum 依赖并添加 Docker repo

yum install -y yum-utils
yum-config-manager \
    --add-repo \
    https://download.docker.com/linux/centos/docker-ce.repo

会看到

添加repo成功

通过 Yum 安装 Docker 程序

yum install docker-ce docker-ce-cli containerd.io

输入指令后需要输入 y 回车确认安装

安装Docker

注意一次安装需要两次确认

二次确认安装

安装过程

Docker安装过程

启动 Docker 服务并设置为自动启动

确保安装完成后使用下方指令开启 Docker 的服务，这样可以确保 Docker 能够始终被正常开启

systemctl start docker
service docker start
systemctl enable docker.service
systemctl enable containerd.service
systemctl status docker.service

Docker服务状态

验证

reboot

重启后查看 Docker 服务

docker

能看到帮助列表弹出代表安装成功

Docker Help

安装 Docker Compose（可选）

下载 Docker Compose

我这里使用的是 1.29.2 版本的 Docker-Compose，这已经是 Docker Compose V1 的最后一个版本了

如需使用 v2 版本的 Docker Compose 可参考 v2 版本的 Linux 官方教程

curl -L "https://github.com/docker/compose/releases/download/1.29.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

下载完毕

给 Docker Compose 添加权限

sudo chmod +x /usr/local/bin/docker-compose

检查安装

docker-compose

能看到帮助列表弹出代表安装成功
