# 饭耳 FanEar 更新记录

每发一个新版本（TestFlight 或 App Store）先在这里写好，再同步到官网 fanear.fandao.dev 的更新记录页。已发布和还没发布的版本都记（CEO 2026-10-13）。写给用户看：说这一版能做什么、改好了什么，不写代码名词。

## 未发布

### 0.1.0（开发中，只在 CEO 自己的手机上装机测试；等苹果开发者账号开通后上 TestFlight）
- 2026-10-14 自动认人：每句话的声音特征在手机上算，换一段录音也认得出是谁；你自己的声音不用注册，按「同一段录音里你最响」自动认出。常出现的声音（累计满 10 分钟、出现在 3 天以上）在「待确认」里问一次「这个声音是谁？」，路人不问。设置里的「声音」能看、改名、删除。声音特征只存在手机上。
- 2026-10-14 （只在开发者自测的版本里，对外版本不带）多模态分析：在设置里选一个能听录音的模型（如 Gemini）后，每块录音和转写发给它，对话页「听出来的」按时间列出在干嘛、什么状态、蛛丝马迹；不选就是关。
- 2026-10-14 整理对话改成先认人、再跑多模态（开了才跑），最后把转写、每句认出的人、多模态结果一起交给大模型：标题、要点、承诺卡会直接写认出的名字和当时的场合。多模态没开或失败时照常整理。
- 2026-10-14 须知和条款升到第 4 版：整理对话时会带上每句认出的人（「我」或你起的名字），开了多模态时还带上多模态分析结果（文字），打开后要重新同意一次。
- 2026-10-14 须知和条款升到第 3 版：加了手机本地认人（声纹）和多模态分析，打开后要重新同意一次。
- 2026-10-14 修好：手机上早就同意过，手表却一直显示「先在手机上同意」、不录音。现在打开手机上的饭耳就会把同意重新发给手表，手表收到就开始录；手机今天页写清是「手表还没收到手机上的同意」，点「让手表接着记」会把同意一起发过去。
- 2026-10-14 第一次打开的「使用前须知」更短：最上面先讲「什么是饭耳」，每条只看标题，想看细节再展开；没勾全就点「同意并开始使用」会震一下，并带你到没勾的那条；勾上「整理时带上健康数据」会直接弹出苹果「健康」授权。
- 2026-10-14 今天页顶上有「待办」：连接 Apple Watch、配置转写、配置大模型三步，做完就消失；右上角的手表按钮能点了，进去看手表连没连、装没装、今天录了多久、传了多久，手表上没装饭耳会教你怎么装。
- 2026-10-14 手表被打断的记录不再一条条占满今天页，收进右上角「中断 N」；时间条上照样看得到缺口。
- 2026-10-14 还没配转文字服务时，录音先存在手机上，不再一块块报「没转成文字」；顶上一条提示带「去配置」直达设置，配好后自动转，以前没转成的也会自动重送一次。
- 2026-10-14 设置里没填全的服务不再写「正在用」，改成黄色「需要完善信息」；去掉了情绪识别；「自定义 / 中转站」改叫「自定义」，可以加多个、可以改名；注册入口挪进各家的页面里（「还没有 key？去注册」）。
- 2026-10-14 手表主屏显示今天录了多久、已传到手机多久、还有几块等传；手表权限弹窗的说明缩成一句。
- 2026-10-14 手表表盘能加饭耳的复杂功能「开始录制」：长按表盘 → 编辑 → 复杂功能 → 饭耳，圆形、角落、长条、一行字的位置都能放。点一下直接打开手表上的饭耳，打开后和平时一样自动开始录（你手动停的除外）。
- 2026-10-14 火山引擎改用新版控制台的 API Key，只填一个 Key；以前填的 APP ID / Access Token 不再使用，要重新填。
- 2026-10-13 （只在开发者自测的版本里，对外版本不带）先把「环境数据」存起来：手表录音时记下手腕怎么动，手机补存最近 7 天的走、跑、开车、骑车、静止和每 5 分钟的步数，地点只记到达和离开。只存在手机上，不发给大模型和任何服务器；删除一段录音时一起删。设置里「环境数据」三项各自能关，下面一张清单写每项存了多少、覆盖多久、最近一条几点、缺了什么，可以导出成文件。条款和隐私说明跟着改了，打开后要重新同意一次。
- 2026-10-13 转文字可以选火山引擎或腾讯云（腾讯云录音文件识别大模型 2.0：分说话人、每句起止时间和语速）。一次用一家，连不上不会自动换；腾讯只收 5MB 以内的音频，超了手机先压小再传。情绪识别成了一个开关，默认关：转写服务按声音给每句标的情绪经常不准，想看可以自己打开；选的服务不支持情绪时开关灰掉。
- 2026-10-13 不会开通？每家转文字服务、每个大模型预设和中转站都有「让 AI 帮你开通」：复制一段提示词给你自己能开浏览器的 AI（豆包、ChatGPT、Claude 等），它带你注册、开通、建只够饭耳用的密钥，付费和实名这些步骤会停下来让你自己做；最后给一段结果，用「粘贴 AI 给的结果」一下填好。连不上或转写、整理失败时有「复制排错提示词」，带上错误码和服务商原话，贴给 AI 问怎么改。
- 2026-10-13 设置里大模型的几个列表都能左滑删除：删供应商、删正在用的模型会先问一句；一家至少留一个模型。
- 2026-10-13 大模型按供应商存：一个服务商或中转站只填一次地址和密钥，下面可以挂很多模型；设置页最上面一行「正在用」，点进去在所有模型里一点就换。添加时可以直接选 DeepSeek、通义千问、豆包、Kimi、智谱 GLM、OpenAI、Anthropic、OpenRouter，每家旁边有「注册」按钮，直接打开官方拿密钥的页面（有中国站、国际站的分开选）；也能「自定义 / 中转站」自己填地址。模型可以从推荐里选、点「从服务商拉取」查这把密钥能用的全部模型，也能自己填；每个模型带它那一家的 LOGO。以前存的大模型原样保留，正在用的不变。
- 2026-10-13 用 Anthropic 官方接口时，Claude Opus 5.5、Sonnet 5.5 也能整理对话了（它们不接受以前那种「强制调用工具」的请求）；中转站里把思考过程写在回答开头的模型（如 MiniMax），也能正确取到结果。
- 2026-10-13 今天页按「一场对话」列：40 分钟的会不再拆成三行，一块录音里先当面聊、后打电话也分成两行；哪里算一场由大模型看内容判断，不按固定时长切。点进去看到整场的原话、心率和谁在说，跨块的同一个人名字和颜色接得上；你改过的照旧优先。
- 2026-10-13 一段对话页底部可以「删除这一段」：录音、文字、整理结果和这一段的承诺卡（包括已进待办的）一起删，删了找不回来；时间线上留一行「你删掉了这一段」。正在处理的那一段处理完才能删。一场对话跨了几段录音时，每段录音一个删除按钮，写明几点到几点；一段录音里还有别的对话时，那部分也会一起删，确认框会写出来。
- 2026-10-13 健康数据只读 15 类（心率、静息心率、心率变异性、呼吸频率、血氧、血压、血糖、步数、活动能量、锻炼时间、日光下时间、环境音量、耳机音量、睡眠），是按你手机里实际有的数据逐项定的；不再申请营养、症状、生殖健康、体能训练等其他类别。
- 2026-10-13 录音时间：一天按 15 分钟一格涂「录 / 不录」。白天的空档手表待命（麦克风开着但不存），到点自动接着记，不用点；每天最长那段不录（一般是夜里）手表真停，第二天到点震一下，点一下开始。在不录时段手动开始，就录到下一个计划切换点。按手机当地时间执行。
- 2026-10-13 被打断时手表和手机同时提醒，只会看到一条；提醒里不出现「录音」两个字，查到正在通话才说「刚来了个电话」。
- 2026-10-13 手机上能看到手表现在在录、待命还是停了；能在手机上让手表停，也能让手表震一下提醒你点一下接着记。
- 2026-10-13 时间线里按计划不录的那段显示成灰色「按计划不录」，不算断；到点后没录上的照旧显示成没录到。
- 2026-10-13 大模型可以存多个、点一下切换；支持 Responses、OpenAI 兼容、Claude 兼容三种接口格式（DeepSeek、通义等走 OpenAI 兼容）。编辑页能看到请求会发到哪个地址，测试连接按整理对话的同一种方式发一次小请求。
- 2026-10-13 原始录音的保留方式加了「最多占 5 / 10 / 20 / 50 GB，满了先删最早的」和「一直留着」，设置页显示现在占了多少、手机还剩多少；只删已经转成文字的录音。调过音量的临时副本转写完就删，不再占空间。
- 2026-10-13 设置页更简单：每块录音固定 15 分钟、上传前调大音量固定开，这两项不再让你调。
- 2026-10-13 健康数据：不再显示让人误以为「已授权」的绿勾；加了「去健康 App 里改」，写明在系统哪里改读取权限。
- 2026-10-13 第一次打开先看「使用前须知」：四条逐条勾（用的是你自己的账号、开发者不存你的数据、免费不保证录全转准、录别人先取得同意），再同意《使用条款与免责声明》《隐私说明》才能用；没同意前手机不往外发录音，手表也不开始录。两份全文在设置里随时能看。
- 2026-10-13 健康数据要不要发给大模型由你选：须知里有一勾（默认不勾），设置里随时改。
- 2026-10-13 新装不再默认填我们的大模型地址，用你自己的；转文字时不再让火山判断说话人性别（没用到）。
- 2026-10-13 出问题时 App 会在手机上记诊断日志（只记哪一步、原因码，不记密钥、对话原文、录音、健康数据），连接测试没连上时会写出原因码，方便查是网络还是证书的问题。
- 2026-10-13 界面换成「声纹」设计：手机有今天、一段对话、待你确认、设置四屏；手表有正在录、被打断、自己停的三种状态；新图标。
- 2026-10-13 整理对话：每段录音转成文字后，大模型给出标题、一句话要点、谁在说话，并抓出「我答应别人的」「别人答应我的」。认不准的人先显示「说话人 N」，你改过的永久有效，重新整理也不覆盖。
- 2026-10-13 认出「我」：从原始录音量每个人的音量，离手表最近、最响的多半是你。
- 2026-10-13 待你确认：每件事可以点「不是」「补充」「进待办」，点「不是」5 秒内能撤销；24 小时没回自动进待办。
- 2026-10-13 手机锁屏时读不到健康数据，这段先不整理，解锁后再整理，不会少带心率。
- 2026-10-12 手表全天录音，按 15 分钟一块传到手机；被来电、Siri、闹钟打断后震动提醒，点一下接着录。
- 2026-10-12 手机收到录音先调响度，再交火山 2.0 转写（分说话人、带情绪）；转文字和大模型的密钥在设置页填，用你自己的账号，App 不经过我们的服务器。
